## Findings

Question: What memory consolidation techniques from post-2024 agent-memory research would most improve an append-only enforcement-bound fact store with a dream-loop (distill → audit → promote) consolidation pipeline, and which papers/projects describe them?

Context used for relevance mapping: an append-only canonical fact store whose entries are enforced or reference (carry an enforcement/authority boundary), with a consolidation pipeline that distills episodic material, audits with a strong model, and promotes verdicts (with enforced/conflicting facts routed to a human queue).

### 1. Preserve authority and source-bound semantics through consolidation — the enforcement-bound store's core risk

- **fact** — "Authority collapse" is now measured: consolidation preserving a claim while erasing the source constraints governing its authorized use occurs in **48 of 49 evaluated configurations** across seven consolidators built on widely-used agent-memory systems and seven LLM backbones; persisted authority labels reduced the mean unauthorized-action rate from 16.9% to 0.0% in end-to-end evaluation. Source: "When Memory Becomes Authority: Benchmarking Authority Collapse at the Memory Consolidation Boundary" (AuthMem-Bench), arXiv 2608.01679, https://arxiv.org/abs/2608.01679.
- **fact** — Consolidation rewrites hedged/casual statements into confident, dated assertions the agent then treats as verified facts; the paper isolates that what the agent responds to is the **confidence of the phrasing, not the source**, and that "a passive 'unverified' tag is ignored" while "keep the tentative phrasing rather than upgrade it" is the store-level fix; a single redundant source restores correct decisions. Source: "Manufactured Confidence: How Memory Consolidation Turns Hearsay into Confident Facts", arXiv 2606.29279, https://arxiv.org/abs/2606.29279.
- **fact** — TrustMem verifies each memory-update transition on **coverage, preservation, and faithfulness** via a Memory Transition Verifier, then uses preference-pair RL over candidate updates; it reduced transition-level omission, corruption, and hallucination by 40.1%, 79.1%, and 50.0% respectively versus the strongest per-error baselines. Source: "TrustMem: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory", arXiv 2606.25161, https://arxiv.org/abs/2606.25161.
- **opinion** — These three map directly onto mini-agi's auditor role: TrustMem defines what the auditor should check (nothing omitted, nothing corrupted, nothing invented), Manufactured Confidence argues the distiller must keep evidential register and never upgrade hedging, and AuthMem-Bench argues `enforced_by`/provenance metadata must survive promotion verbatim (the store already routes enforced facts and conflicts to a human queue — that matches the measured fix of persisting authority labels).

### 2. Gate *when* consolidation runs — cheap idle loop, not eager extraction

- **fact** — RecMem keeps incoming interactions in a "subconscious" embedding layer and invokes the LLM to extract episodic/semantic memory **only when sustained recurrence** of semantically similar interactions is observed; it reduced memory-construction token cost of three SOTA memory systems by up to 87% while exceeding their accuracy. Source: "RecMem: Recurrence-based Memory Consolidation for Efficient and Effective Long-Running LLM Agents" (ACL 2026 Findings), arXiv 2605.16045, https://arxiv.org/abs/2605.16045.
- **fact** — D-MEM decouples short-term interaction from cognitive restructuring via a Fast/Slow routing system on Reward Prediction Error: routine low-RPE inputs bypass or cache in an O(1) buffer, while high-RPE inputs (factual contradictions, preference shifts) trigger the O(N) memory-evolution pipeline; it reduces token consumption by over 80% and removes the O(N²) write-latency bottleneck of "append-and-evolve" systems like A-MEM. Source: "D-MEM: Dopamine-Gated Agentic Memory via Reward Prediction Error Routing", arXiv 2603.14597, https://arxiv.org/abs/2603.14597.
- **opinion** — This is direct support for the existing `dream --idle` (load + freshness guarded, busy box skips) design: consolidation should be selective and surprise/utility-gated rather than run on every append; D-MEM's "contradiction or preference shift triggers restructuring" is precisely the signal that should route a fact to the enforcement/conflict queue.

### 3. Represent consolidated memory so the append-only constraint costs nothing

- **fact** — Mem0's automatic extraction path is **additive by default**: on "I moved from Austin to Seattle" it stores the new fact without silently rewriting the old one; correction requires explicit `update`/`delete` operations. Its store separates SQL (facts/metadata = source of truth), vector (embeddings), and entity stores; retrieval fuses semantic, keyword, entity, and temporal signals. Source: Mem0 official docs "How Mem0 Works", https://docs.mem0.ai/core-concepts/how-it-works.
- **fact** — The Mem0 architecture dynamically extracts, consolidates, and retrieves salient information; on the LOCOMO benchmark it beat all baselines across single-hop/temporal/multi-hop/open-domain questions with 26% relative LLM-as-judge gain over OpenAI, ~91% lower p95 latency, and >90% token savings; the graph variant adds ~2% overall. Source: "Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory", arXiv 2504.19413, https://arxiv.org/abs/2504.19413.
- **fact** — Graphiti (Zep's open-source engine) treats each fact as having a **validity window**: "when information changes, old facts are invalidated — not deleted", every entity/relationship traces back to the raw episodes that produced it, new data integrates incrementally "without batch recomputation", and contradiction handling is "automatic fact invalidation with temporal history preserved" (bi-temporal tracking). Source: Graphiti README (getzep/graphiti), https://github.com/getzep/graphiti.
- **fact** — The Zep paper reports Graphiti outperforming MemGPT on the Deep Memory Retrieval benchmark (94.8% vs 93.4%) and up to 18.5% accuracy gains with 90% lower latency on LongMemEval, especially on cross-session synthesis. Source: "Zep: A Temporal Knowledge Graph Architecture for Agent Memory", arXiv 2501.13956, https://arxiv.org/abs/2501.13956.
- **fact** — HippoRAG 2 frames memory as non-parametric continual learning: it "recognizes and uses connections in new knowledge" by integrating new passages online into a knowledge graph with Personalized PageRank, staying cost/latency efficient in online processes and exceeding standard RAG on factual, sense-making, and associative memory tasks (+7% associative over a SOTA embedding model). Source: "From RAG to Memory: Non-Parametric Continual Learning for Large Language Models" (ICML 2025), arXiv 2502.14802; project README, https://github.com/OSU-NLP-Group/HippoRAG.
- **fact** — A-MEM (Zettelkasten-style agentic memory) creates structured notes with links and enables **memory evolution**: integrating a new memory can trigger updates to the contextual representations/attributes of existing memories. Source: "A-MEM: Agentic Memory for LLM Agents" (NeurIPS 2025), arXiv 2502.12110, https://arxiv.org/abs/2502.12110.
- **fact** — GAM explicitly **decouples memory encoding from consolidation**: ongoing dialogue is held in an event-progression graph and integrated into a topic-associative network only upon semantic shifts, minimizing interference while preserving long-term consistency (SOTA on LoCoMo and LongDialQA). Source: "GAM: Hierarchical Graph-based Agentic Memory for LLM Agents", arXiv 2604.12285, https://arxiv.org/abs/2604.12285.
- **fact** — TiMem consolidates raw conversational observations through a Temporal Memory Tree into progressively abstracted persona representations with semantic-guided consolidation (no fine-tuning), reaching 75.30% on LoCoMo / 76.88% on LongMemEval-S while cutting recalled memory length 52.20%. Source: "TiMem: Temporal-Hierarchical Memory Consolidation for Long-Horizon Conversational Agents" (ACL 2026 Findings), arXiv 2601.02845, https://arxiv.org/abs/2601.02845.
- **fact** — MemoryOS uses a hierarchical store (short/mid/long-term): short→mid updates via a dialogue-chain FIFO principle, mid→long via a segmented-page organization strategy (+49.11% F1, +46.18% BLEU-1 over baselines on LoCoMo). Source: "Memory OS of AI Agent", arXiv 2506.06326, https://arxiv.org/abs/2506.06326.
- **opinion** — For an append-only store, Graphiti's invalidate-not-delete plus episode provenance is the strongest fit: it lets a superseded fact stay in the log while its *authority* moves to the newer fact — no destructive update needed, and contradiction is handled structurally rather than by an LLM judgment (which is what the README claims versus GraphRAG).

### 4. Explicit retention/forgetting policy — otherwise the append-only log is unbounded

- **fact** — A biologically-grounded agent memory architecture combines **sleep-phase consolidation, interference-based forgetting, engram maturation, reconsolidation upon retrieval**, entity knowledge graphs, and hybrid multi-cue retrieval; deduplication-based consolidation achieved 97.2% retention precision with 58% store reduction (+21.8 pp over baseline). Source: "Human-Inspired Memory Architecture for LLM Agents", arXiv 2605.08538, https://arxiv.org/abs/2605.08538.
- **opinion** — An append-only store needs an explicit retention model (dedup, invalidation, or archival tier) or the consolidation pipeline's search quality degrades; this paper offers measured dedup numbers and a synthetic calibration methodology that avoids benchmark leakage.

### 5. Conceptual frame for where consolidation ends

- **fact** — A position paper argues current agent memory (vector stores, RAG, scratchpads) implements lookup, not memory: drawing on Complementary Learning Systems theory it claims biological intelligence pairs fast hippocampal exemplar storage with slow neocortical weight consolidation, and "current AI agents implement only the first half." Source: "Contextual Agentic Memory is a Memo, Not True Memory", arXiv 2604.27707, https://arxiv.org/abs/2604.27707.
- **fact** — The TMLR survey "A Survey of Agent Memory in the Second Half" reports hundreds of agent-memory papers in 2025 and frames memory as the substrate of self-evolution: short-term memory gates which experiences are abstracted, long-term memory consolidates them into reusable knowledge and skills, and "memory management itself is becoming a trainable capability." Source: arXiv 2602.06052, https://arxiv.org/abs/2602.06052.

## Verdict

**Established (verified from primary sources above):** Post-2024 agent-memory research has converged on five consolidation techniques directly relevant to a dream-loop fact store: (1) verifiable/authority-preserving consolidation — measured authority collapse when source constraints are dropped (AuthMem-Bench), confidence-inflation from rewriting hedges (Manufactured Confidence), and transition verification on coverage/preservation/faithfulness (TrustMem); (2) surprise/recurrence-gated consolidation instead of eager extraction (RecMem, D-MEM), with large token-cost reductions (up to 80–87%); (3) additive, provenance-linked representation — Mem0's additive-by-default extraction, Graphiti's invalidate-not-delete validity windows with episode provenance and incremental (no-recompute) integration, HippoRAG 2's online continual learning; (4) memory evolution/consolidation decoupled from encoding (A-MEM, GAM, TiMem, MemoryOS); (5) explicit retention policy (Human-Inspired Memory Architecture: dedup consolidation at 97.2% retention precision / 58% store reduction).

**Uncertain:** The reported numbers are self-reported on benchmark-specific setups (LoCoMo, LongMemEval, DMR, MemAgentBench, HaluMem); there is no cross-system, same-harness comparison of consolidation correctness, and the "Memo, Not True Memory" paper argues these stores are lookup layers, not consolidated weights — a claim these systems do not address. Whether authority preservation and enforcement survive in practice in a graph-based store (vs flat facts) is only tested in the flat-fact setting.

**What would settle it:** (a) a same-harness comparison of distiller/auditor pairs on a single episodic corpus measuring omission/corruption/hallucination/authority-preservation (e.g., run TrustMem's verifier and AuthMem-Bench's harness against a Graphiti-style store and an append-only flat store); (b) applying AuthMem-Bench's paired-source protocol to the dream-loop's promote step specifically; (c) an empirical test of RecMem/D-MEM-style gating on the `dream --idle` cadence measuring consolidation token cost vs retained-fact accuracy.
