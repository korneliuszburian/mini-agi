## S-000 (general)

DPR's dense retriever outperforms a strong Lucene-BM25 system by 9-19% absolute in top-20 passage retrieval accuracy for open-domain QA (Karpukhin et al., EMNLP 2020). Source: arXiv:2004.04906 abstract.

## S-001 (general)

BM25 underperforms dense retrievers on agent-memory fact recall: LongMemEval retriever ablation (Value=Session, K=V) gives BM25 Recall@5=0.634 / NDCG@5=0.516 vs Contriever 0.723/0.634 vs Stella V5 1.5B 0.720/0.594 (Wu et al., ICLR 2025). Source: arXiv:2410.10813v2, Table 9, Appendix E.2.

## S-002 (general)

BM25 is a robust retrieval baseline; re-ranking and late-interaction models on average achieve the best zero-shot BEIR performances but at high computational cost, while dense and sparse-retrieval models often underperform. Exact per-dataset BEIR nDCG@10 values were not extractable (paper HTML render 404'd). Source: arXiv:2104.08663 abstract.

## S-003 (general)

AgentIR (2026 preprint) reports on LoCoMo (n=1,982) that BM25 alone is already the strongest single system and a hybrid cascade can skip the dense channel with no accuracy loss — this is an estimate from a single 2026 preprint, not independently verified. Source: arXiv:2605.25092 abstract.

## S-004 (general)

Dense retrieval beats BM25 on agent-memory recall by ~9-14 Recall@5 points: LongMemEval Table 9, Contriever 0.723 vs BM25 0.634 (+0.089). Source: arXiv:2410.10813v2, Appendix E.2.

## S-005 (general)

Dense-only retrieval roughly doubles lexical accuracy on an 18-language benchmark: MIRACL dev nDCG@10 average BM25 31.9 → M3-Embedding Dense 69.2. Source: arXiv:2402.03216, Table 1.

## S-006 (general)

Embedding-based retrieval alone does not close the gap to human fact recall in long conversations: on LongMemEval even commercial memory chatbots with dense memory (ChatGPT GPT-4o 57.7%, Coze 33.0%) drop 37% and 64% vs offline reading of full context (91.8%). Source: arXiv:2410.10813v2, Figure 3a.

## S-007 (general)

Time-aware memory retrieval measurably improves temporal-reasoning recall: LongMemEval time-aware query expansion improves recall by an average of 11.3% using rounds as the value and 6.8% using sessions (6.8%-11.3% 'when a strong LLM is employed for query expansion'). Source: arXiv:2410.10813v2, Section 5.4/Table 4 and abstract.

## S-008 (general)

Temporal reasoning is the single hardest fact-recall category across agent-memory benchmarks: LoCoMo human temporal F1=92.6 vs best base model GPT-4-turbo=10.4; long-context LLMs lag human levels especially in temporal reasoning by 73%. Source: arXiv:2402.17753, Table 2 + Section 6.

## S-009 (general)

A temporal knowledge-graph memory improves temporal-reasoning QA by a large relative margin over full-context reading: Zep (Graphiti temporal KG) on LongMemEvalS temporal-reasoning, gpt-4o full-context 45.1% → Zep 62.4% (+38.4% rel); gpt-4o-mini 36.5% → 54.1% (+48.2% rel). Source: arXiv:2501.13956, Table 3.

## S-010 (general)

MemoryBank uses an Ebbinghaus Forgetting Curve to forget/reinforce memories, but its evaluation is qualitative (empathic responses, memory recall) with no published quantitative accuracy comparison vs a baseline — fact/estimate. Source: arXiv:2305.10250.

## S-011 (general)

TiMem (2026 preprint) claims 75.30% on LoCoMo and 76.88% on LongMemEval-S as 'state-of-the-art' — an estimate from a recent preprint (ACL 2026 Findings claim), unverified and not independently corroborated. Source: arXiv:2601.02845 abstract.

## S-012 (general)

Entity/graph retrieval gives the biggest measured gains on multi-hop fact integration: HippoRAG R@5 on 2WikiMultiHopQA BM25 61.9 / ColBERTv2 68.2 / HippoRAG 89.1 (+20 points); on MuSiQue 41.2/49.2/51.9 (~+3); QA F1 2Wiki 43.3→59.5 (+16.2), MuSiQue 26.4→29.8. Single-step HippoRAG is 10-30x cheaper and 6-13x faster than IRCoT with comparable/better performance. Source: arXiv:2405.14831, Tables 2-4, abstract.

## S-013 (general)

Graph memory beats summarization-based and flat memory baselines on conversational fact recall: Zep on LongMemEvalS overall accuracy gpt-4o full-context 60.2% → Zep 71.2% (+11.0 points, ~18% rel; abstract 'up to 18.5%'); gpt-4o-mini 55.4% → 63.8%. On DMR (500 multi-session conversations): Zep 94.8% vs MemGPT 93.4% vs full-context 94.4% vs session summaries 78.6%. Caveat: Zep is vendor-authored and the DMR gap to full-context is small (0.4). Source: arXiv:2501.13956, Tables 1-3.

## S-014 (general)

GraphRAG leads to substantial improvements over a conventional RAG baseline in comprehensiveness and diversity of generated answers for global/corpus-level sensemaking over ~1M-token corpora, but the paper reports no numeric accuracy in the abstract — fact/estimate. Source: arXiv:2404.16130 abstract.

## S-015 (general)

Graphs do not help every category: structured fact extraction can hurt single-session detail recall — Zep regressed on single-session-assistant questions (gpt-4o 94.6% → 80.4%, −17.7% rel). Source: arXiv:2501.13956, Table 3.

## S-016 (general)

Hybrid (dense + sparse) and fused (dense + sparse + multi-vector) retrieval consistently beat each single signal: M3-Embedding MIRACL nDCG@10 Dense 69.2 / Sparse 53.9 / Multi-vec 70.5 / Dense+Sparse 70.4 / All 71.5; long-doc MLDR Dense 52.5 / Sparse 62.2 / Dense+Sparse 64.8 / All 65.0; NarrativeQA Dense 48.7 / Sparse 57.5 / Multi-vec 55.4 / Dense+Sparse 60.1 / All 61.7. Source: arXiv:2402.03216, Tables 1, 3, 4.

## S-017 (general)

Hybrid indexing (multiple keys per memory item) improves agent-memory recall: LongMemEval key expansion (K = value + extracted user facts) over K = value gives +9.4% avg recall@k and +5.4% end-to-end QA accuracy; key merging ≫ post-retrieval rank merging (Table 10). Source: arXiv:2410.10813v2, Section 5.3, Tables 3, 10.

## S-018 (general)

Production agent-memory systems combine all three retrieval signals: Zep runs Okapi BM25, cosine embedding similarity, and breadth-first graph search in parallel, then reranks (incl. Reciprocal Rank Fusion and cross-encoder rerankers). Source: arXiv:2501.13956, Sections 3.1-3.2.

## S-019 (general)

RRF's superiority over other fusion methods is a referenced method claim (Cormack et al., SIGIR 2009, cited via Zep Section 3.2) — not independently fetched this pass; treat as referenced, not verified. Source: Zep, arXiv:2501.13956, Section 3.2.

## S-020 (general)

Conversation-store granularity interacts with fusion — what you retrieve matters as much as how: LoCoMo RAG with GPT-3.5-turbo-16k overall QA F1 none 22.4 / dialog top-5 31.7 / summary top-5 32.5 / observations (facts) top-5 41.4; 'a noticeable 5% improvement … when the input is top 5 relevant observations instead of pure conversation logs'. Source: arXiv:2402.17753, Table 3 + Section 6.1.

## S-021 (general)

Long-context/retrieval gains are large relative to base LLMs but far from human: LoCoMo improvements of 22-66% from long-context/RAG yet still lag human by 56%; human overall F1 87.9 vs best long-context 37.8 (GPT-3.5-turbo-16k @16k tokens) vs best RAG 41.4. Source: arXiv:2402.17753, Tables 2-3 + Section 6.

## S-022 (general)

Retrieval reading strategy is a separate measurable lever: LongMemEval, even with perfect retrieval, Chain-of-Note + structured data format improves QA accuracy by as much as 10 absolute points across three LLMs; on LongMemEvalS long-context LLMs drop 30-60% vs oracle retrieval. Source: arXiv:2410.10813v2, Section 5.5 + Figure 3b.

## S-023 (general)

Retrieval techniques are complements, not alternatives — the biggest gains come from stacking them: Zep = temporal KG + hybrid lexical/dense/graph retrieval; HippoRAG = KG + embeddings + PPR; LongMemEval's best config = session decomposition + fact-augmented keys + time-aware query expansion. Sources: arXiv:2501.13956; arXiv:2405.14831; arXiv:2410.10813v2.

## S-024 (general)

Cross-benchmark retrieval numbers are not comparable; each row's comparison is only valid within its own benchmark/model. A single head-to-head benchmark running all five retrieval strategies (BM25, dense, recency-aware, entity graph, hybrids) on the same agent-memory QA set with the same reader LLM does not yet exist in peer-reviewed sources; LongMemEval's retriever ablation (Table 9) is the closest existing partial comparison.

## S-025 (general)

LoCoMo's paper is machine-converted HTML; one table cell (Dialog k=10 Multi-Hop R@k = 247.4) is a rendering artifact and was treated as 24.7. PDF-only sections were not read; all cited numbers come from abstracts or HTML-rendered full text.

## S-026 (general)

Zep, M3-Embedding, and HippoRAG benchmark numbers are author-reported; Zep is the vendor of the tested product. 2026 preprint headline numbers (AgentIR, TiMem) were verified only at abstract level and could not be independently corroborated; several look implausibly high next to peer-reviewed baselines.
