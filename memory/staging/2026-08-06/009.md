## S-000 (general)

BM25 (lexical/BM25 keyword search) is the baseline against which dense and graph retrieval methods are measured, and it is often weaker on fact recall than embeddings once the corpus is large.

## S-001 (general)

DPR dense retriever outperforms a Lucene-BM25 system by 9%-19% absolute in top-20 passage retrieval accuracy for open-domain QA (DPR, arXiv:2004.04906 abstract).

## S-002 (general)

On agent-memory recall BM25 underperforms dense retrievers: LongMemEval retriever ablation (Value=Session, K=V), BM25 Recall@5 = 0.634 / NDCG@5 = 0.516 vs Contriever 0.723 / 0.634 vs Stella V5 1.5B 0.720 / 0.594 (LongMemEval, arXiv:2410.10813v2, Table 9, Appendix E.2).

## S-003 (general)

BEIR: BM25 is a robust baseline and re-ranking and late-interaction-based models on average achieve the best zero-shot performances but at high computational costs; in contrast, dense and sparse-retrieval models often underperform (BEIR, arXiv:2104.08663 abstract).

## S-004 (general)

BEIR's exact per-dataset nDCG@10 values could not be extracted — the paper's HTML render 404'd — so only the abstract's qualitative claim is cited (uncertain).

## S-005 (general)

AgentIR (2026 preprint, estimate, not independently verified) reports on LoCoMo (n=1,982) that 'BM25 alone is already the strongest single system' and a hybrid cascade that skips the dense channel with no accuracy loss (AgentIR, arXiv:2605.25092 abstract).

## S-006 (general)

Dense retrieval is the single largest accuracy jump over lexical search for open-domain fact retrieval (DPR: 9-19% absolute top-20 accuracy over Lucene-BM25).

## S-007 (general)

In agent-memory recall dense retrievers beat BM25 by ~9-14 Recall@5 points (LongMemEval Table 9: Contriever 0.723 vs BM25 0.634, +0.089).

## S-008 (general)

Dense-only retrieval roughly doubles lexical accuracy on an 18-language benchmark: MIRACL dev nDCG@10 BM25 31.9 vs M3-Embedding Dense 69.2 (M3-Embedding, arXiv:2402.03216, Table 1).

## S-009 (general)

End-to-end, embedding-based retrieval alone does not close the gap to human fact recall in long conversations: on LongMemEval even commercial memory chatbots with dense memory (ChatGPT GPT-4o 57.7%, Coze 33.0%) drop 37% and 64% vs offline reading of full context (91.8%) (LongMemEval, arXiv:2410.10813v2, Figure 3a).

## S-010 (general)

Making memory retrieval time-aware measurably improves temporal-reasoning recall: LongMemEval time-aware query expansion improves recall by an average of 11.3% using rounds as the value and 6.8% using sessions, 'when a strong LLM is employed for query expansion' (arXiv:2410.10813v2, Section 5.4/Table 4 and abstract).

## S-011 (general)

Temporal reasoning is the single hardest fact-recall category across agent-memory benchmarks: LoCoMo human temporal F1 = 92.6 vs best base model GPT-4-turbo = 10.4; long-context LLMs 'lag behind human levels… especially in temporal reasoning, by 73%' (LoCoMo, arXiv:2402.17753, Table 2 + Section 6).

## S-012 (general)

A temporal knowledge-graph memory improves temporal-reasoning QA by a large relative margin over full-context reading: Zep (Graphiti temporal KG) on LongMemEvalS temporal-reasoning gpt-4o full-context 45.1% → Zep 62.4% (+38.4% rel); gpt-4o-mini 36.5% → 54.1% (+48.2% rel) (Zep, arXiv:2501.13956, Table 3).

## S-013 (general)

MemoryBank uses an Ebbinghaus Forgetting Curve to forget/reinforce memories, but its evaluation is qualitative (empathic responses, memory recall) with no quantitative accuracy comparison vs a plain memory reported in the abstract/paper (fact/estimate; MemoryBank, arXiv:2305.10250).

## S-014 (general)

TiMem (recent 2026 preprint, ACL 2026 Findings claim, estimate, unverified) reports 75.30% on LoCoMo and 76.88% on LongMemEval-S as 'state-of-the-art', verified only at the abstract level and not independently corroborated (TiMem, arXiv:2601.02845 abstract).

## S-015 (general)

Graph retrieval gives the biggest measured gains on multi-hop fact integration (facts split across passages): HippoRAG R@5 on 2WikiMultiHopQA BM25 61.9 / ColBERTv2 68.2 / HippoRAG 89.1 (+20 points over best baseline); on MuSiQue 41.2 / 49.2 / 51.9 (~+3 points); QA F1 2Wiki 43.3 → 59.5 (+16.2), MuSiQue 26.4 → 29.8 (HippoRAG, arXiv:2405.14831, Tables 2-4).

## S-016 (general)

Single-step HippoRAG 'achieves comparable or better performance than iterative retrieval like IRCoT while being 10-30 times cheaper and 6-13 times faster' (HippoRAG, arXiv:2405.14831 abstract).

## S-017 (general)

Graph memory beats summarization-based and flat memory baselines on conversational fact recall: Zep on LongMemEvalS overall accuracy gpt-4o full-context 60.2% → Zep 71.2% (+11.0 points, ~18% rel, abstract 'up to 18.5%'); gpt-4o-mini 55.4% → 63.8%. DMR (500 multi-session conversations): Zep 94.8% vs MemGPT 93.4% vs full-context 94.4% vs session summaries 78.6%. Caveat: Zep is vendor-authored and the DMR gap to full-context is small (0.4) (Zep, arXiv:2501.13956, Tables 1-3).

## S-018 (general)

GraphRAG improves global/corpus-level fact synthesis but the measured effect is judged qualitatively: 'substantial improvements over a conventional RAG baseline for both the comprehensiveness and diversity of generated answers' for global sensemaking over ~1M-token corpora; no numeric accuracy reported in the abstract (fact/estimate; GraphRAG, arXiv:2404.16130 abstract).

## S-019 (general)

Graphs do not help every category — structured fact extraction can hurt single-session detail recall: Zep regressed on single-session-assistant questions (gpt-4o 94.6% → 80.4%, -17.7% rel) (Zep, arXiv:2501.13956, Table 3).

## S-020 (general)

Hybrid (dense + sparse) and fused (dense + sparse + multi-vector) retrieval consistently beat each single signal: M3-Embedding MIRACL nDCG@10 Dense 69.2 / Sparse 53.9 / Multi-vec 70.5 / Dense+Sparse 70.4 / All 71.5; long-doc MLDR Dense 52.5 / Sparse 62.2 / Dense+Sparse 64.8 / All 65.0; NarrativeQA Dense 48.7 / Sparse 57.5 / Multi-vec 55.4 / Dense+Sparse 60.1 / All 61.7 (M3-Embedding, arXiv:2402.03216, Tables 1, 3, 4).

## S-021 (general)

Hybrid indexing (multiple keys per memory item: K = value + extracted user facts) improves agent-memory recall: +9.4% avg recall@k and +5.4% end-to-end QA accuracy over K = value; key merging ≫ post-retrieval rank merging (LongMemEval, arXiv:2410.10813v2, Section 5.3, Tables 3, 10).

## S-022 (general)

Production agent-memory systems combine lexical + semantic + graph retrieval: Zep runs Okapi BM25, cosine embedding similarity, and breadth-first graph search in parallel, then reranks (incl. Reciprocal Rank Fusion and cross-encoder rerankers) (Zep, arXiv:2501.13956, Sections 3.1-3.2).

## S-023 (general)

RRF's own measured claims (Cormack, Clarke & Buettcher, SIGIR 2009) were referenced by Zep but not independently fetched — treat RRF's superiority as a referenced method claim (opinion/hedge).

## S-024 (general)

Conversation-store granularity interacts with fusion — what you retrieve matters as much as how: LoCoMo RAG with GPT-3.5-turbo-16k overall QA F1 none 22.4 / dialog top-5 31.7 / summary top-5 32.5 / observations (facts) top-5 41.4; 'a noticeable 5% improvement … when the input is top 5 relevant observations instead of pure conversation logs' (LoCoMo, arXiv:2402.17753, Table 3 + Section 6.1).

## S-025 (general)

Long-context/RAG gains are large relative to base LLMs but far from human: LoCoMo reports improvements ranging 22-66% from long-context/RAG but still 'significantly lag behind human levels (by 56%)'; human overall F1 87.9 vs best long-context 37.8 (GPT-3.5-turbo-16k @16k tokens) vs best RAG 41.4 (arXiv:2402.17753, Table 2-3 + Section 6).

## S-026 (general)

Retrieval reading strategy is a separate measurable lever: even with perfect retrieval, Chain-of-Note + structured data format improves QA accuracy 'by as much as 10 absolute points across three LLMs'; on LongMemEvalS long-context LLMs drop 30-60% vs oracle retrieval (LongMemEval, arXiv:2410.10813v2, Section 5.5 + Figure 3b).

## S-027 (general)

Techniques are complements, not alternatives — the biggest gains come from stacking them: Zep = temporal KG + hybrid lexical/dense/graph retrieval; HippoRAG = KG + embeddings + PPR; LongMemEval's best config = session decomposition + fact-augmented keys + time-aware query expansion (arXiv:2501.13956; arXiv:2405.14831; arXiv:2410.10813v2).

## S-028 (general)

Cross-benchmark numbers are not comparable; each row's comparison is only within its own benchmark and model.

## S-029 (general)

Whether temporal ordering alone (without a graph) helps ordinary fact recall — as opposed to temporal-reasoning questions — is not cleanly isolated in any single paper reached (uncertain).

## S-030 (general)

A single head-to-head benchmark running all five retrieval strategies (BM25, dense, recency-aware, entity graph, hybrids) on the same agent-memory QA set with the same reader LLM does not yet exist in the peer-reviewed sources reached; the LongMemEval retriever ablation (Table 9) is the closest existing partial comparison.

## S-031 (general)

Zep, M3-Embedding, and HippoRAG numbers are author-reported; Zep is the vendor of the tested product (hedge on those measurements).

## S-032 (general)

2026 preprints (AgentIR, TiMem and similar) report headline numbers on LoCoMo/LongMemEval verified only at the abstract level and not independently corroborated; several look implausibly high next to the peer-reviewed baselines (hedge).

## S-033 (general)

LoCoMo's paper is machine-converted HTML; one table cell (Dialog k=10 Multi-Hop R@k = 247.4) is a rendering artifact treated as 24.7; PDF-only sections of the papers were not read; all cited numbers come from abstracts or HTML-rendered full text (data-quality caveat).

## S-034 (general)

Established high-confidence finding: embeddings beat BM25 for fact retrieval in general open-domain QA (DPR: +9-19% top-20 acc) and on agent-memory recall specifically (LongMemEval: +0.089 Recall@5).

## S-035 (general)

Established high-confidence finding: temporal-aware retrieval measurably improves temporal-reasoning recall (LongMemEval: +6.8-11.3%).

## S-036 (general)

Established high-confidence finding: entity/graph retrieval gives the largest gains on multi-hop fact integration (HippoRAG: +20 R@5 points on 2WikiMultiHopQA) and on long-conversation QA (Zep: +11.0 points over full-context on LongMemEvalS, with a documented regression on single-session-assistant questions).

## S-037 (general)

Established high-confidence finding: hybrid fusion beats any single signal (M3-Embedding: All > Dense+Sparse > Dense on MIRACL 71.5 > 70.4 > 69.2; LongMemEval multi-key indexing: +9.4% recall@k), and winning agent-memory systems stack temporal + graph + hybrid lexical/dense retrieval.

## S-038 (general)

Established high-confidence finding: storing memory as extracted facts (observations) rather than raw or summarized dialogue is a large, separate lever (LoCoMo: 41.4 vs 31.7-32.5 overall F1).

## S-039 (general)

MemGPT (arXiv:2310.08560) defines the DMR (Dialogue Memory Retrieval) benchmark used by Zep for multi-session conversational memory evaluation.
