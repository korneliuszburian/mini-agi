## F-000 `3f23602cd01322dc`

Authority collapse is measured in agent-memory consolidation: 48 of 49 evaluated configurations across seven consolidators and seven LLM backbones erode source constraints governing a claim's authorized use when they consolidate; persisting authority labels reduced mean unauthorized-action rate from 16.9% to 0.0% in end-to-end evaluation. Source: AuthMem-Bench, arXiv 2608.01679.

## F-001 `faedc0f0a4b0184b`

Consolidation rewrites hedged/casual statements into confident dated assertions the agent treats as verified facts; the agent responds to phrasing confidence, not source; a passive 'unverified' tag is ignored, while keeping tentative phrasing rather than upgrading it is the store-level fix; a single redundant source restores correct decisions. Source: 'Manufactured Confidence', arXiv 2606.29279.

## F-002 `77e29c7c6707642d`

TrustMem verifies each memory-update transition on coverage, preservation, and faithfulness via a Memory Transition Verifier, then uses preference-pair RL over candidate updates; it reduced transition-level omission, corruption, and hallucination by 40.1%, 79.1%, and 50.0% respectively versus strongest per-error baselines. Source: arXiv 2606.25161.

## F-003 `4a16c7ba303c62e7`

RecMem keeps incoming interactions in a 'subconscious' embedding layer and invokes the LLM to extract episodic/semantic memory only on sustained recurrence of semantically similar interactions; it reduced memory-construction token cost of three SOTA memory systems by up to 87% while exceeding their accuracy. Source: ACL 2026 Findings, arXiv 2605.16045.

## F-004 `9a057f6afaa72539`

D-MEM decouples short-term interaction from cognitive restructuring via Fast/Slow routing on Reward Prediction Error: routine low-RPE inputs bypass or cache in an O(1) buffer, high-RPE inputs (factual contradictions, preference shifts) trigger the O(N) memory-evolution pipeline; reduces token consumption over 80% and removes the O(N^2) write-latency bottleneck of append-and-evolve systems like A-MEM. Source: arXiv 2603.14597.

## F-005 `ccecea1af23feed5`

Mem0's automatic extraction is additive by default: on changed facts it stores the new fact without silently rewriting the old one; correction requires explicit update/delete operations; the store separates SQL (facts/metadata as source of truth), vector (embeddings), and entity stores, fusing semantic, keyword, entity, and temporal retrieval signals. Source: Mem0 docs 'How Mem0 Works'.

## F-006 `5e22ecc2aa426efa`

Mem0's architecture dynamically extracts, consolidates, and retrieves salient information; on LOCOMO it beat all baselines across single-hop/temporal/multi-hop/open-domain questions with 26% relative LLM-as-judge gain over OpenAI, ~91% lower p95 latency, and >90% token savings; the graph variant adds ~2% overall. Source: 'Mem0: Building Production-Ready AI Agents', arXiv 2504.19413.

## F-007 `92823ba871a2eaae`

Graphiti (Zep's open-source engine) treats each fact as having a validity window: changed information is invalidated, not deleted; every entity/relationship traces back to the raw episodes that produced it; new data integrates incrementally without batch recomputation; contradictions are handled by automatic fact invalidation with temporal history preserved (bi-temporal tracking). Source: getzep/graphiti README.

## F-008 `b6fef0270ed8d28d`

Graphiti outperformed MemGPT on Deep Memory Retrieval (94.8% vs 93.4%) and achieved up to 18.5% accuracy gains with 90% lower latency on LongMemEval, especially on cross-session synthesis. Source: 'Zep: A Temporal Knowledge Graph Architecture for Agent Memory', arXiv 2501.13956.

## F-009 `e794ca1248d1924c`

HippoRAG 2 frames memory as non-parametric continual learning, integrating new passages online into a knowledge graph with Personalized PageRank, staying cost/latency efficient and exceeding standard RAG on factual, sense-making, and associative memory tasks (+7% associative over a SOTA embedding model). Source: ICML 2025, arXiv 2502.14802.

## F-010 `8014b8b82d793b73`

A-MEM (Zettelkasten-style agentic memory) creates structured notes with links and enables memory evolution: integrating a new memory can trigger updates to contextual representations/attributes of existing memories. Source: NeurIPS 2025, arXiv 2502.12110.

## F-011 `075b797922584daa`

GAM explicitly decouples memory encoding from consolidation: ongoing dialogue lives in an event-progression graph and is integrated into a topic-associative network only on semantic shifts, minimizing interference while preserving long-term consistency (SOTA on LoCoMo and LongDialQA). Source: arXiv 2604.12285.

## F-012 `7087735a64f76c95`

TiMem consolidates raw conversational observations through a Temporal Memory Tree into progressively abstracted persona representations with semantic-guided consolidation (no fine-tuning), reaching 75.30% on LoCoMo / 76.88% on LongMemEval-S while cutting recalled memory length 52.20%. Source: ACL 2026 Findings, arXiv 2601.02845.

## F-013 `40e1e6b577d42b61`

MemoryOS uses a hierarchical short/mid/long-term store: short-to-mid updates via a dialogue-chain FIFO principle, mid-to-long via segmented-page organization (+49.11% F1, +46.18% BLEU-1 over baselines on LoCoMo). Source: arXiv 2506.06326.

## F-014 `0b44c39d153c71e2`

A biologically-grounded agent memory architecture combines sleep-phase consolidation, interference-based forgetting, engram maturation, reconsolidation upon retrieval, entity knowledge graphs, and hybrid multi-cue retrieval; deduplication-based consolidation achieved 97.2% retention precision with 58% store reduction (+21.8 pp over baseline). Source: 'Human-Inspired Memory Architecture for LLM Agents', arXiv 2605.08538.

## F-015 `8742eae87151033d`

A position paper argues current agent memory (vector stores, RAG, scratchpads) implements lookup, not memory: drawing on Complementary Learning Systems theory, biological intelligence pairs fast hippocampal exemplar storage with slow neocortical weight consolidation, and current AI agents implement only the first half. Source: 'Contextual Agentic Memory is a Memo, Not True Memory', arXiv 2604.27707.

## F-016 `a668572194f1c30e`

The TMLR survey 'A Survey of Agent Memory in the Second Half' reports hundreds of agent-memory papers in 2025 and frames memory as the substrate of self-evolution: short-term memory gates which experiences are abstracted, long-term memory consolidates them into reusable knowledge and skills, and memory management itself is becoming a trainable capability. Source: arXiv 2602.06052.

## F-017 `cf99d7577e330864`

Reported consolidation numbers across the research are self-reported on benchmark-specific setups (LoCoMo, LongMemEval, DMR, MemAgentBench, HaluMem); there is no cross-system same-harness comparison of consolidation correctness, and authority-preservation survival in a graph-based store (vs flat facts) is only tested in the flat-fact setting.
