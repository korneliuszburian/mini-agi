## F-000 `8479b0749854fe46`

MAST (Cemri et al., UC Berkeley; arXiv 2503.13657) defines 14 LLM-agent failure modes in 3 categories: FC1 System Design Issues (disobey task spec 11.8%, disobey role spec 1.5%, step repetition 15.7%, loss of conversation history 2.8%, unaware of stopping conditions 12.4%), FC2 Inter-Agent Misalignment (conversation reset 2.2%, fail to ask for clarification 6.8%, task derailment 7.4%, information withholding 0.85%, ignored other agent's input 1.9%, reasoning-action mismatch 13.2%), FC3 Task Verification (premature termination 6.2%, no/incomplete verification 8.2%, incorrect verification 9.1%).

## F-001 `973e990075c8a7fd`

MAST (arXiv 2503.13657) was derived by Grounded Theory analysis of 150 traces across 5 frameworks, refined via 3 inter-annotator rounds (kappa=0.88), then LLM-as-judge annotation of 1,642 traces (kappa=0.77 vs. humans).

## F-002 `aa17692c22a78738`

Interaction-Centric Taxonomy (Raj, Gupta, Mahmoud et al., Scale AI; arXiv 2607.28802, July 2026) defines 41 LLM-agent failure modes, each assigned to an interaction edge between two components and a fault side (model vs. other); components are Model, Owner, Grader, Third party, Context, Memory, Tool, Local env., External env. grouped into three families (User, Harness, Environment); 36 modes are model-side, 5 are component-side.

## F-003 `f7a62764ca74d0e9`

Interaction-Centric Taxonomy (arXiv 2607.28802) was grounded in 40 worked examples (E1-E40) drawn from public benchmarks, model system cards, published reports, and logged agent trajectories; labels assigned by tracing the earliest unrecoverable failure ('root-cause principle'); strongest independent reasoning judge reaches Cohen's kappa=0.76 vs. human category labels, highest pairwise judge agreement kappa=0.84.

## F-004 `38956b8103d9e760`

Interaction-Centric Taxonomy (arXiv 2607.28802) names modes including Over-initiative, Under-initiative, Satisficing, Instruction-Following Failure, Reasoning Failure, Unauthorized Irreversible Action, Sycophancy, Domain Knowledge Deficit, Value Misalignment, Instruction-Grader Mismatch, Specification Gaming, Evaluation Awareness, Indirect Prompt Injection, Contextual Sycophancy, State Tracking Failure, Goal Drift, Context Rationale Erosion, Missed Write, State Staleness, Overgeneralization, Memory Rationale Erosion, Pollution, Redundancy, Missed Read, Memory Following Failure, Incorrect Tool Selection, Tool Hallucination, Tool Feedback Neglect, Tool Recovery Failure, Malformed Arguments, Suboptimal Arguments, Mistranslation, Delegation Failure, Communication Failure, Recovery Failure, Service Failure, Stale State Delivery, Observation Failure.

## F-005 `f4b23532d8f51878`

Longitudinal silent-failure taxonomy (Wu; arXiv 2606.14589, 'When Errors Become Narratives') defines five mechanism-oriented classes of agent silent failures: (A) environment and platform quirks, (B) design-assumption mismatches, (C) error swallowing and dilution, (D) chained hallucination and fabrication (described as the unique-to-LLM 'fail-plausible' pattern), (E) operational omission and forensic blind spots.

## F-006 `984129939642011a`

Longitudinal silent-failure study (Wu; arXiv 2606.14589) covered an 8-week study of one production personal-assistant runtime (~40 scheduled jobs, 8 LLM providers) with 22 documented root-caused incidents; reported ~70% of silent failures caught by human user-view observation, 0% ex-ante prevention vs. 87% regression-blocking in retrospective audit, incident latency 13 hours to 60 days.

## F-007 `02a02d256e8ffada`

Aegis taxonomy (Song et al., U. Toronto/Vector; arXiv 2508.19504) defines 6 agent-environment failure modes in 3 categories: Exploration Failures (State-space Navigation Failure, State Awareness Failure), Exploitation Failures (Tool Output Processing Failure split into comparison/calculation/retrieval/sorting, Domain Rule Violation distinguishing invalid action vs. lack of correct action, User Instruction Following Failure), plus Resource Exhaustion (turn/token limit).

## F-008 `d0a70761a296b570`

Aegis (arXiv 2508.19504) was measured on 142 failed traces / 3,656 turns across 5 benchmarks (TauBench airline & retail, BFCL file system, CRM-Arena, MedAgentBench) and 3 models (GPT-4.1, GPT-4.1 mini, o3); failures localized to the first unsuccessful subtask using an HTN-inspired subtask abstraction; resource exhaustion accounted for 45%/83% of retail/CRM failures under GPT-4.1.

## F-009 `d897024c3f240a4b`

DEFT deep-research failure taxonomy (Zhang et al., OPPO AI Agent Team; arXiv 2512.01948) defines 14 failure modes under 3 core categories: Reasoning (Failure to Understand Requirements 10.55%, Lack of Analytical Depth 11.09%, Limited Analytical Scope 0.90%, Rigid Planning Strategy 5.60%), Retrieval (Insufficient External Information Acquisition 16.30%, Information Handling Deficiency 2.26%, Information Integration Failure 2.91%, Information Representation Misalignment 2.91%, Verification Mechanism Failure 8.72%), Generation (Redundant Content Piling 2.51%, Structural Organization Dysfunction 2.26%, Content Specification Deviation 10.73%, Deficient Analytical Rigor 4.31%, Strategic Content Fabrication 18.95%).

## F-010 `57c6cc3485ade4ed`

DEFT (arXiv 2512.01948) was derived by grounded theory on ~1,000 reports from 10+ deep research agents: open coding by 5 LLM coders (Claude Opus 4.1, Gemini 2.5 Pro, Grok 4, DeepSeek-V3.1, Qwen3-Max-Preview) yielding 51 concepts, axial coding in 3 ICR rounds with 3 domain experts sampling 24-54 records with Krippendorff's alpha, selective coding to 3 core categories, theoretical-saturation check on unseen agents (WebThinker, OpenManus), human-LLM inter-coder reliability alpha~0.80-0.90.

## F-011 `554b0217976296b3`

DeepVerifier DRA failure taxonomy (Wan et al., CUHK/Tencent; arXiv 2601.15808, ACL 2026 Findings) defines 5 major classes and 13 sub-classes built to drive rubric-based verification: Problem Understanding, Finding Sources (dominant — e.g., consulting wrong evidence, generic searches), Reasoning (premature conclusions, misinterpretation, hallucinated/overconfident claims), Action Errors, Max Step Reached; 13 sub-class names shown in Fig. 3 were not all reproduced in the fetched text.

## F-012 `bacb0e234ea35e04`

DeepVerifier (arXiv 2601.15808) was measured on 2,997 agent actions across 90 tasks on WebAggregatorQA (CK-Pro agent, Claude-3.7-Sonnet backbone); 555 error points annotated by two staff annotators against human reference solutions with 63% cross-annotator overlap; taxonomy built by iterative clustering/labeling of error points.

## F-013 `7e96686c5bcb8461`

Three-tier task-phase taxonomy (Lu, Li, Huo; arXiv 2508.13143, ASE 2025 NIER) aligns agent failures to task phases: planning errors, task execution issues, incorrect response generation; benchmarked on 34 programmable tasks with 3 open-source agent frameworks x 2 LLM backbones, ~50% observed task completion, causes induced from in-depth failure analysis.

## F-014 `9ef58d49f849ae77`

Tool-agent parameter-filling taxonomy (Xiong et al.; arXiv 2507.15296, 'Butterfly Effects in Toolchains') defines five failure categories derived from the invocation chain of a mainstream tool agent; parameter-name-hallucination failures reportedly stem chiefly from LLM limits, other categories trace to input sources; measured with 15 input perturbation methods correlated against failure categories. Individual category names are not enumerated in the abstract and could not be verified (arXiv HTML 404, PDF unreadable).

## F-015 `0e16f2f530c68f78`

AgentEval failure taxonomy (Guo, Wu, Yiu; arXiv 2604.23581, ACL 2026 Industry) is a hierarchical failure taxonomy with 3 levels and 21 subcategories used for DAG-structured step-level evaluation with root-cause attribution; category names not enumerated in the abstract.

## F-016 `7135e88581ab3411`

AgentEval (arXiv 2604.23581) was measured on 450 test cases across three production workflows and two agent model families: Cohen's kappa=0.84 vs. human experts, 72% root-cause accuracy, failure-detection recall 0.89 vs. 0.41 for end-to-end; transfer shown on tau-bench and SWE-bench traces.

## F-017 `284dea68d04d19f5`

Tool-invocation reliability taxonomy (Huang, Malwe, Wang; arXiv 2601.16280, ICAIBD 2026) is a 12-category error taxonomy spanning tool initialization, parameter handling, execution, and result interpretation; category names not enumerated in the abstract; measured on 1,980 deterministic test instances across open-weight (Qwen2.5 series, Functionary) and proprietary models (GPT-4, Claude 3.5/3.7), with tool-initialization failures identified as the primary bottleneck for smaller models.

## F-018 `bdfabd828b164b23`

SpreadsheetBench 2 (Zhu et al.; arXiv 2606.29955) provides a trajectory-analysis failure taxonomy; dominant bottlenecks reported as insufficient spreadsheet inspection and incorrect target-cell selection.

## F-019 `f9a27846604a85ce`

NOMAD (Giannouris & Ananiadou; arXiv 2511.22409) presents an error taxonomy for LLM-generated UML diagrams covering structural, relationship, and semantic/logical errors.

## F-020 `249cc166e0a084fe`

Harness-sensitivity taxonomy (Cho et al.; arXiv 2605.26731) is a six-label taxonomy from a 432-run controlled experiment; format_violation dominates capable models while wrong_file dominates low-capability models.

## F-021 `89d1caf3454ccaea`

There is no single canonical LLM-agent failure taxonomy — the space is fragmented by scope (multi-agent, agent-environment, deep research, tool-use, production runtime) and by whether categories name the responsible component or the observable symptom; no survey synthesizing them was located in the search.

## F-022 `c1a0b768075c2467`

Verdict of the research: besides MAST there is a substantial, actively growing body of empirically derived LLM-agent failure taxonomies, all reporting explicit measurement corpora (trace counts, annotator counts, agreement statistics, task/turn counts); the strongest-documented are the Interaction-Centric Taxonomy (41 modes; 40 grounded worked examples; judge reproducibility kappa=0.76), DEFT (14 modes; grounded theory over ~1,000 DRA reports with Krippendorff's-alpha validation), Aegis (6 modes; 142 annotated failed traces), DeepVerifier (5 classes/13 sub-classes; 555 annotated error points), and the longitudinal silent-failure taxonomy (5 classes; 22 production incidents).
