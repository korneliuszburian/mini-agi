LangSmith annotation queues group runs or whole threads, prescribe a rubric ("Instructions" + feedback keys), and track reviewer progress; queues present one item at a time ("single-run") or two runs side-by-side ("pairwise"), with item states Needs Review → Needs Others' Review → Completed.

## F-001 `7f9242706e36c133`

LangSmith annotation-queue collaborator settings let an item be held until every workspace member marks it Done, or require a set number of reviewers per run, and can name assigned reviewers explicitly; reservations lock an item to a reviewer for a set time and expire/release it if the reviewer leaves without marking Done, so the number of items visible to each reviewer can differ from the total queue size.

## F-002 `8fb8a22a126c8ff7`

## F-003 `693010a524f0a9fb`

Braintrust human review defines review scores (categorical, continuous, free-form) that appear in logs/experiments/datasets, and manages review work via a dedicated Review page with views (Awaiting review, Assigned to me, Completed), SQL filtering, and a kanban layout (Backlog / Pending / Complete); rows can be assigned to team members who get email (and optional Slack DM) notifications.

## F-004 `49b7fb8236915e10`

## F-013 `cb86a545057edd22`

## F-014 `7cfe9661cd15e22a`

## F-015 `b3d72fc2c65ef3e3`
