## F-000 `1eb6cac2ee3c0b55`

FrugalGPT defines three cost-reduction strategies: prompt adaptation, LLM approximation, and LLM cascade (query a list of LLMs sequentially; a scoring function g(q, answer) in [0,1] and a learned per-model threshold decide when to stop and return). The cascade is a length-3 list scored via a DistilBERT regressor. (FrugalGPT, arXiv 2305.05176, §3-4)

## F-001 `53b44257c13294e1`

Hybrid LLM routes each query to exactly one of two models (large vs small), never calling multiple LLMs per query. The router is a BERT-style encoder (DeBERTa-v3-large) trained to predict the quality gap H(x)=q(S(x))−q(L(x)) where q is BART score; a test-time threshold on the router score trades quality for cost. (Hybrid LLM, arXiv 2404.14618v1, §2.2, §3.1-3.3)

## F-002 `9cc229d3928af9fd`

RouteLLM trains a binary 'win prediction' router P_θ(wins|q) from Chatbot Arena human preference data and routes to the strong model iff P(wins|q) >= cost threshold α. Four parameterizations: similarity-weighted (SW) Bradley–Terry ranking, matrix factorization, BERT classifier, causal LLM classifier (Llama 3 8B). (RouteLLM, arXiv 2406.18665v4, §3.1, §4.2)

## F-003 `c576cfdd5214f4fd`

'Task-classification' routers categorize queries into pre-defined categories and pick the best-scoring model — e.g., vLLM Semantic Router uses a ModernBERT categorizer. (RouterArena, arXiv 2510.00202v3, §6.1)

## F-004 `300485f9871ece7c`

FrugalGPT cascade (3 LLMs, learned confidence thresholds) achieves cost savings to match the best individual LLM's accuracy: 98.3% on HEADLINES (GPT-4 best), 73.3% on OVERRULING (GPT-4), 59.2% on COQA (GPT-3 best). (FrugalGPT, arXiv 2305.05176, Table 3)

## F-010 `cef70c90b6220520`

Hybrid LLM headline: up to 40% fewer calls to the large model with no drop in response quality (abstract); 22% fewer GPT-3.5-turbo calls at <1% BART-score drop (intro, Fig 1c). (Hybrid LLM, arXiv 2404.14618v1)

## F-011 `6977145a51d83491`

Hybrid LLM routing value depends sharply on the model-pair quality gap: at a 20% cost advantage the small-gap pair (Llama-2 7b/13b) loses <=0.1% BART quality, the large-gap pair (FLAN-t5 800m/Llama-2 13b) loses up to 5.8%. When the gap is large, training on Pr[H>=0] labels is near-useless ('0 for almost 90% of queries'); a label-relaxation transformation (Pr[H>=−t]) recovers a usable signal. (Hybrid LLM, arXiv 2404.14618v1, Table 1, §3.3, Fig 4a)

## F-012 `e151279bfa369f9a`

Hybrid LLM with thresholds tuned to keep BART drop <1%, achievable cost advantage is pair-dependent: Llama-2 7b/13b → >96% cost advantage; Llama-2 13b/GPT-3.5-turbo → only ~15%; FLAN-t5 800m/Llama-2 13b → ~5%. (Hybrid LLM, arXiv 2404.14618v1, §4.5, Table 3)

## F-013 `135c69977d75322e`

Hybrid LLM router latency overhead is negligible relative to generation: DeBERTa router 0.036±0.002 s/query vs Llama-2 13b generation 14.61±0.27 s (router ~10× faster than the fastest LLM, FLAN-t5 800m at 0.46 s). (Hybrid LLM, arXiv 2404.14618v1, §4.4, Table 2)

## F-014 `feeed923077d1e1f`

Hybrid LLM router quality transfer to new model pairs degrades with quality-gap correlation: at high correlation (r=0.76) 20% cost advantage costs <=1.6% quality, 40% costs <=4.1%; at low correlation (r=0.06) it fails. (Hybrid LLM, arXiv 2404.14618v1, §4.7, Fig 8)

## F-015 `74a333f06b0e1b1b`

Recurring across independent LLM-routing papers: (1) the achievable tradeoff is dominated by the size of the weak/strong quality gap and the training-data distribution match (augmentation and low-data regimes matter more than router architecture); (2) routers over-deploy the strong model in practice (RouterArena normalized deferral curve), so the frontier is far from the oracle; (3) router overhead itself is measurable and non-trivial (latency, embedding API calls, per-request cost) but small vs generation cost.

## F-016 `e9faf4c799927644`

Cross-paper comparison of LLM routers is apples-to-oranges: different model pools, different quality metrics (BART score vs accuracy vs LLM-judge), different cost assumptions (e.g., RouteLLM's GPT-4/Mixtral ~100× ratio), and 2023–2025 price baselines. Confidence-threshold cascade papers (FrugalGPT, 2502.11021) report large savings but on few datasets and with authors' own thresholds.
